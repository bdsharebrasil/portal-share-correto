🎯 O QUE FOI CRIADO
═════════════════════════════════════════════════════════════════════════════

Um sistema automático que consolida dados de rateios de despesas no dashboard,
mostrando para cada cliente/sócio:
  ✅ Aeronave
  ✅ Horas voadas
  ✅ Percentual de participação (calculado)
  ✅ Valor rateado
  ✅ Categoria de despesa
  ✅ Status de reembolso

🔄 FLUXO AUTOMÁTICO
═════════════════════════════════════════════════════════════════════════════

Usuário Cria Rateio
   ↓
Sistema Insere em rateio_despesas
   ↓
Usuário Marca como "Consolidado"
   ↓
⚡ TRIGGER AUTOMÁTICO ⚡
   └─ Executa: consolidar_despesas_para_historico()
   └─ Busca horas voadas
   └─ Calcula percentual de participação
   └─ Filtra categorias permitidas
   └─ Insere em historico_rateio_consolidado
   ↓
Dashboard Busca Dados Automaticamente
   ↓
Tabela é Exibida com Filtros
